# SIMD classic parity baseline, 2026-11-02

Source: `be0dfccc47ed1f8b5b41a1f75910d0a307fe67cf`, branch
`jairus/json-go-brr`. Native simdjson 5.0.4, pinned commit
`3b0b2b53aaffb46208817821dce2cd47a5e6bb2a`. Frozen run:
`build/simdjson-parity/runs/paritycurrent01/`.

Five alternating fresh native/V8 processes per layout; V8 `--no-liftoff`,
strict syntax, changing inputs, owned output and eight retained results.
The shared timer preserves positive fractional milliseconds. Fourteen layouts
use 500 operations per phase; OTFCC and FGO use 100. These are single-revision
native comparisons, not optimization speedups against earlier 100-operation
runs. Longer warmup and allocation history can affect results.

Every layout passes twenty complete owned-output and retained-result
comparisons. All 48 required phase medians exist. **22 pass and 26 miss** the
latency target. No whole-goal completion is established.

Artifacts: `build/simdjson-parity/comparisons/current-parity-<layout>-v8/`
contains invocation, compiler/runtime provenance, process logs, statuses,
individual measurements and median TSVs. Console summaries are preserved as
`build/simdjson-parity/current-<layout>-summary.log`. Large regenerated oracle
JSON files were removed only after successful complete comparisons; inputs,
binaries, manifests and verdict logs remain.

Reproduction for one frozen layout:

```sh
python3 bench/simdjson/compare.py --case citm_catalog-min \
  --labels paritycurrent01 --backends v8 --modes simd --pairs 5 \
  --output current-parity-citm-confirm-v8 --gate-classic v8
```
